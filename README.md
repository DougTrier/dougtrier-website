## About this repository

This repository contains the published website files and this README. The site is hosted on GitHub Pages with the custom domain `dougtrier.com`.

Each application's source code, documentation, releases, and downloads are maintained in its own repository. The website links to those existing releases; application installers are not stored here.

The local website builder, development files, and private review notes are not included. Existing application websites, including GenX Streamer, are maintained separately.
